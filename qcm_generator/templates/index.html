📝 QCM Generator

Generate LaTeX multiple choice questionnaires with ease

📚 Help & Guide

📋 Format

Header (first 5 lines):

  • Line 1: QCM Title
  • Line 2: Author
  • Line 3: School
  • Line 4: Course
  • Line 5: Date

Questions:

  • Start each question with Q followed by the question text
  • List answers below (one per line)
  • Leave a blank line between questions

🎨 LaTeX Support

You can use LaTeX math notation:

  • Inline math: $x^2 + y^2 = z^2$
  • Display math: \[E = mc^2\]
  • Images: \includegraphics[width=0.5\textwidth]{path}
